# 메모리 (세션 흐름 2/5)

목적: 세션이 끊기거나 맥락이 요약되어도 다음 세션(또는 이 세션의 뒷부분)이 그대로 이어받게 한다. 메모리 폴더는 시스템 프롬프트의 "Memory" 절에 적힌 경로다(이 프로젝트: `~/.claude/projects/-Users-taehyeonpark-Desktop-dev-roblox-map/memory/`).

## 1. 이번 세션 메모 쓰기

파일 `cell-<칸ID>-session.md` 하나(같은 칸 메모가 있으면 새로 만들지 말고 고친다):

```markdown
---
name: cell-<칸ID>-session
description: <칸ID> 세션(<날짜>): <목표 한 줄>, 지금 <단계>
metadata:
  type: project
---

- 칸: <칸ID> (<위치·등급·건물 수>)
- 목표: <이번 세션에서 끝낼 것>
- 시작 상태: 커밋 <hash>, 사이클 단계 <...>, Studio <모드·부품 수·저장 여부>
- 계획: <남은 단계 순서>
- 진행: (구현·검증 중에 단계가 끝날 때마다 한 줄씩 덧붙인다)

**Why:** 세션 흐름(인지 → 메모리 → 구현 → 검증 → 기록), 칸 하나에 세션 하나.
**How to apply:** 다음 세션은 이 메모의 "진행" 마지막 줄부터 이어간다. 칸이 끝나 기록이 끝나면 이 메모를 지운다.
```

날짜는 절대 날짜로. 개인 정보(사람 이름, 번호판, 실제 상호)는 쓰지 않는다.

## 2. MEMORY.md 색인

`MEMORY.md`에 한 줄: `- [<칸ID> 세션](cell-<칸ID>-session.md) — <목표>, <단계>`. 이미 있으면 고친다.

## 3. 정리

- 이미 끝나 `aidlc-docs/lessons.md`와 커밋에 반영된 칸 세션 메모는 지우고 색인 줄도 지운다.
- 오래된 handoff 메모가 가리키는 일이 끝났으면 지운다.
- 메모와 저장소가 다르면 저장소가 맞다. 메모를 고친다.

## 4. 구현·검증 중

단계가 끝날 때마다 "진행"에 한 줄(예: `2026-10-15 판단 223/223 기록, report 일치율 62%`). 맥락이 길어져도 이 메모로 이어간다.

그다음 `cycle-build`로 간다.
