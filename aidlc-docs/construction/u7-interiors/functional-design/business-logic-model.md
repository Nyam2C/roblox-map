단계 3(2026-10-14). 규칙은 `business-rules.md`(BR-I*), 개념·꾸러미는 `domain-entities.md`.

```
build_luau.plan_cell(칸, 건물, 도로, cfg(구역 합침), 판단, 보정, 세부, 간판 자산, 나무, 등급)

    외관 = box_items, roof_items, body_items, front_items, yard_items, sign_items   (내부가 있으면 BR-I1.3, BR-I4.3, 창 두께만 다름)
    내부 = interiors.interior_items(body, frame, cfg, tier)  (새 모듈 src/interiors.py, 계산만, 입출력 없음)
  가로 = streets.*                                           (지금 그대로)
```

모든 좌표 계산은 Python(`interiors.py`), Studio는 부품만 만든다(지금 결정 그대로). 엘리베이터 스크립트만 게임 중에 돈다.

## 2. 건물 하나의 내부 순서 (`interior_items`)

1. **할지 정하기**(BR-I1): 등급 3, 끄기, 수작업 건물, `is_body` 아님 → 빈 목록.
2. **층 높이**(BR-I5): y0, y_k(k = 1 … F−1), 지붕 종류에 따라 맨 위 천장(평지붕이면 옥상 바닥 H + 0.6).
3. **계단실 자리**(BR-I6): 길이 L 계산 → 앞 박스 → 가장 큰 박스 순으로 들어가는지 보고 모서리·방향 결정. 없으면 경고.
4. **코어 자리**(BR-I7): 엘리베이터 대상이면 계단실 옆 2.0 × 2.0.
5. **벽 구간**(BR-I2, BR-I3): 박스마다 면마다 표본으로 맞닿음·묻힘 구간을 빼고, 현관(BR-I4)·가게 앞면 구멍을 뺀 구간을 벽 부품으로.
6. **현관**(BR-I4): 문틀 3, 디딤판 0~2.
7. **바닥**(BR-I5): 층마다 박스마다 판, 계단실·코어 박스는 구멍 둘레로 나눔. 계단 구멍 난간.
8. **계단**(BR-I6, BR-I8): 층 사이마다 오르막 A·참·오르막 B. 평지붕이면 옥상까지 한 단 더, `#cap` 나눔과 계단탑(이 둘은 외관 쪽 `body_items`가 계단실 자리를 받아 처리).
9. **엘리베이터**(BR-I7): 코어 벽 3, 층마다 문.
10. **방**(BR-I9): 층·박스마다 가장 큰 빈 직사각형, 비워 둘 곳 목록.
11. **꾸러미**(BR-I10, BR-I11): 층마다 꾸러미 이름 → 방 크기에 맞춰 부품 놓기(BR-I12), 겹치거나 안 들어가면 그 부품만 빠짐.
12. **조명**(BR-I13): 방마다 등판, 해당 방만 `lt`.
13. **예산 확인**(BR-I14): 층당·건물당 상한을 넘으면 뒤쪽 꾸러미 부품부터 빼고 경고(테스트에서는 실패).

출력: `layout.Item` 목록(종류 `wall` / `interior`, `owner` = 건물 ID, 이름 `<건물>#i<층>-<박스>-<꼬리><번호>`). 같은 입력이면 같은 목록.

## 3. 외관 쪽 바뀌는 곳 (내부가 있을 때만)

| 지금 | 바뀜 |
|---|---|
| `building` 박스(색칠한 꽉 찬 박스) | `hv=1` 부피(보이지 않음, 속성 그대로) |
| 현관 문짝 `#dr`, 가게 문짝 | 만들지 않음(문틀은 내부 쪽) |
| 가게 앞면 유리 한 장 | 문 자리에서 둘로 나눔 |
| 창(두께 0.10, 벽 밖에) | 두께 0.10 + 0.25, 안쪽으로 늘려 안에서도 보임 |
| 평지붕 `#cap` 한 장 | 계단실 구멍 둘레 2~3장 |
| 옥상 물건 | 계단탑과 1 m 안에서 겹치면 뺌 |

## 4. Studio와 게임

- `MapBuilder`: 새 키 `hv`, `lt`, `p`, `ef`/`eF`를 읽는다. 건물 항목을 `owner`별 Model로 묶고 `ModelStreamingMode`를 정한다(BR-I15). 바꾸면 Clone 후 원본 Destroy로 교체(lessons).
- `Elevator.server.luau`(새): 시작할 때와 `CollectionService:GetInstanceAddedSignal("Elevator")`에서 프롬프트를 단다. 이동은 `PivotTo`.
- 스트리밍 설정은 단계 7(사용자 `.rbxl` 복사본 뒤)에 켠다. 단계 4 시험은 `MCP_Test` 안, 스트리밍 끈 채로.
