# 로켓 쇼핑 카트 (2026-10-16)

사용자: "쇼핑 카트 뒤에 부스터 달린거 하자 드리프트 부스터 가속 다 있는거" → "일단 만들어봐". 정할 것 세 가지는 Claude 기본안(어디서나 꺼냄 / 박으면 튕기기만 / 점프대 됨)으로 갔다. 바꾸고 싶으면 아래 숫자나 규칙을 고친다.

## 코드
- `studio/ServerScriptService/Cart.server.luau`: `CartToggle`(타기·내리기, 쿨다운 0.6초, 킥보드 중·의자에 앉은 중에는 안 됨), 카트 부품 21개를 HumanoidRootPart에 용접(충돌·질량 없음), 0.8 stud 낮게 앉힘, 속성 `Carting`·`CartMaxSpeed`(80). `CartFx`(""/boost/turbo/d1~d3)를 검사해 캐릭터 속성 `CartFx`로.
- `studio/StarterPlayerScripts/CartClient.client.luau`: 앉는 동작(Animate의 sit), 운전, 드리프트, 부스터, 점프대, 따라오는 카메라, 화면(속도·부스터 게이지), 모든 카트의 불꽃·불티·빛·바퀴 소리.
- 킥보드 서버는 `Carting`이면 거절, 패러글라이더는 펼 때 카트에서 먼저 내림. 설치는 `minimap.py` SOURCES(install-u6).

## 조작
| 입력 | PC | 휴대폰 |
|---|---|---|
| 타기·내리기 | C | 카트 버튼 |
| 가속·브레이크·후진 | W / S | 조이스틱 위·아래 |
| 핸들 | A / D | 조이스틱 옆 |
| 드리프트 | Space 누르고 있기 | 드리프트 버튼 |
| 부스터 | E 누르고 있기 | 부스터 버튼 |

입력은 카메라 기준으로 읽는다(이 장소에는 PlayerModule이 없어 원래 입력 벡터를 못 받음). 타는 동안 카메라는 카트 뒤 16 stud·위 6.5 stud에서 따라온다(Scriptable, Camera 우선순위 바로 뒤).

## 숫자
- 최고 80 km/h, 0→80 약 2.7초, 브레이크 70, 후진 최고 22.
- 드리프트: 25 이상에서 핸들 + Space로 시작, 15 아래거나 미끄러짐 75° 넘으면 끝. 회전 1.3배, 미끄러짐 시간 상수 0.3초(시험에서 약 40°). 0.6/1.4/2.4초 버티면 파랑/주황/보라 불티, 놓으면 터보 0.6/1.0/1.5초(최고 1.35배)와 게이지 +0.12/단계.
- 부스터: 최고 1.5배, 게이지 1이 3초, 자연 충전 초당 0.04.
- 박기: 30 넘는 속도에서 갑자기 25 넘게 줄면 뒤로 튕김(넘어지지 않음).
- 점프대: 킥보드와 같은 높이 규칙(속도 비례, 공중 중력 0.5).

## 시험 (Studio Play, 2026-10-16)
- 학교 운동장에서: 0→76 km/h, 드리프트 미끄러짐 40°·파랑 → 터보, 부스터 게이지 1 → 0.41, 벽에 박으면 튕김.
- 원 그리며 드리프트·부스터 15초: 평균 59.9 FPS, 1초 최저 58.8, 가장 느린 프레임 23 ms.
- 타기·내리기 0.05초, 내리면 걷기 속도·점프·동작·카메라 원래대로, 카트 중 킥보드 거절.
- 접속 직후(칸 불러오는 몇 초)에는 첫 요청이 늦게 처리될 수 있다.

## 남은 것
- 드리프트 끼익·부스터 쉭 소리(지금은 킥보드 바퀴 소리를 낮춰 씀). 크리에이터 스토어 소리 ID를 찾으면 넣는다.
- 두 명 시험(다른 사람 카트의 불꽃·불티가 보이는지), 휴대폰 버튼 위치.
