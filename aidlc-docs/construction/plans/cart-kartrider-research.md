# 카트 조작감: 카트라이더 레퍼런스 조사 (2026-10-16)

사용자: "카트라이더와 완벽한 조작감을 목표로하고 레퍼런스 조사를 해보자 유출된 자료라던가 누가 구현한거 혹은 리버스엔지니어링 가능한 그런요소 있는지 파악해봐".

## 쓰지 않는 것
- 유출 자료(소스·내부 문서), 클라이언트 디컴파일·메모리 읽기·파일 추출. 넥슨 저작물이고 저작권법의 역분석 예외(호환 목적)에 해당하지 않으며 게임 약관 위반이다. Roblox 검수(남의 IP)와도 걸린다.
- 이름·로고·카트 모양·효과음 같은 넥슨 자산. 따라 하는 것은 "조작 규칙과 숫자"뿐이다(CLAUDE.md 공개 레퍼런스 원칙과 같음).

## 카트라이더식과 지금 카트의 차이
| | 지금(마리오카트식) | 카트라이더식 |
|---|---|---|
| 드리프트 깊이 | 핸들 방향으로만 조절 | Shift를 누르는 길이(짧게 = 얕고 감속 작음, 길게 = 깊고 감속 큼) |
| 드리프트 보상 | 버틴 시간 → 3단 불티 → 놓으면 터보 | 드리프트할수록 게이지가 참 → 꽉 차면 부스터 1개 저장(최대 2개) → Ctrl로 사용 |
| 짧은 가속 | 터보(자동) | 순간부스터: 드리프트 끝에 앞키를 뗐다 다시 누르는 타이밍 |
| 끝내기 | Space를 놓음 | 반대 방향키(커팅), 앞키 |
| 기술 | 없음 | 커팅, 톡톡이·끌기, 연타 드리프트, 스핀턴, 출발 부스터, 드래프트 |
| 키 | WASD, Space, E | 방향키(또는 WASD), Shift, Ctrl |

## 합법적으로 더 할 수 있는 것
1. 공개 영상 프레임 분석: 플레이 영상에서 속도계 숫자, 드리프트 각도, 순간부스터 시점을 프레임 단위로 재서 숫자를 맞춘다(보기만 하고 영상은 저장소에 넣지 않음).
2. 직접 플레이: 서비스 중인 카트라이더 러쉬플러스(모바일)나 재출시판으로 감을 잡는다.
3. 사용자 감: 사용자가 카트라이더를 해 봤다면 타 보고 "무겁다·가볍다·늦다"를 알려 주는 것이 가장 빠르다.
