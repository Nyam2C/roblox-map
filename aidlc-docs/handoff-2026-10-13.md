1. **걷기 FPS 재기**(S-13, 간판 이미지와 학교 v4 뒤). 마지막 측정은 Studio 창이 뒤에 있어 15 FPS 고정(무효). 방법: 사용자가 Studio 창을 앞에 둔 상태에서 Play → `execute_luau`(Client)로 `RenderStepped` 75초 기록(StringValue `U5_FPS2`에 JSON) → `character_navigation`(Client)으로 (-310,4,-525) → (-610,4,-755) → (-680,4,-470) → (-745,4,40) → (-520,4,80) 순서(계남로 → 계남로260번길 → 옥산로113번길; 각 호출은 도착까지 막힌다) → 값 읽기. 결과를 `aidlc-docs/construction/build-and-test/performance-test-instructions.md`의 `[SIGN_FPS]` 자리에 쓰고 커밋.
2. **검수 거부 간판 3장**: Roblox가 처음 37장 중 3장을 "필터링"했다(그중 맥주잔 '호프' 1장은 이미 기록에서 뺐고 이름 풀에서 제거). 나머지 2~3장의 자산 ID를 사용자에게 받아 `data/build/8930e0af13bffff/asset-index.json`으로 열쇠를 찾고 `signs/8930e0af13bffff.json`에서 그 열쇠를 지우면 글자 간판으로 돌아간다(`build_luau.py` → `chunks.json` → Studio 재생성). 사용자는 대시보드(작품 → 개발 아이템 → 이미지)에서 그 항목을 보관(Archive).

## 주의(이번 세션에서 배운 것)

- Roblox 업로드: 술·담배·도박 어휘나 아이콘이 있으면 계정이 검수된다(`403 User is moderated`). 막히면 재시도하지 말고 멈춘다. 20장 묶음 2개까지는 병렬 호출이 됐다.
- 캡처는 만든 직후 SurfaceGui가 비어 보인다. 1분 뒤 다시 찍는다. 큰 글씨는 `PixelsPerStud`를 10쯤으로 낮춘다(TextSize 상한 100 px).
- `Builder.add`는 `{created, skipped_manual}` 표를 돌려준다. Edit 호출 전에 `get_studio_state`로 Play 여부를 본다(사용자가 Play를 켜 두는 일이 있었다). Studio가 다시 연결되면 `studio_id`가 바뀐다(`list_roblox_studios`).
- 이미지 생성 엔드포인트는 4개 병렬에서 429를 낸다. 2개가 안전. raw 답은 캐시라 마무리만 바꾸면 호출 0.
- 로컬 서버는 끝났으면 내린다(`pkill -f "http.server 8765"`, 8766). 이번 세션 끝에는 둘 다 내렸다.
- 편집 카메라를 `Scriptable`로 바꿨으면 `Fixed`로 되돌린다(사용자가 마우스로 못 움직였던 원인).
