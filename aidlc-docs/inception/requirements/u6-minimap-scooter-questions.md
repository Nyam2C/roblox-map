## 방법 요약 (질문에 답하기 전에 읽는 것)

- **지도**: 플레이어 화면(ScreenGui)에 작은 지도를 오른쪽 위에 둔다. 내 위치는 캐릭터의 stud 좌표를 지도 픽셀로 바꿔 표시한다(좌표 바꾸는 계산은 Python에서 만들고 테스트한다. 이 맵은 이미 동쪽 +X, 북쪽 −Z, 3.6 stud/m로 정해져 있다).
- **킥보드**: 서버 스크립트가 타기/내리기 요청을 받아 확인한 뒤 걷는 속도를 올리고 킥보드 모양(상자 몇 개와 바퀴, 충돌 없음)을 발에 붙인다. 물리 차량(VehicleSeat)은 쓰지 않는다. 좁은 골목에서 끼이고 휴대폰 조작이 어려워서다. 다른 플레이어에게도 보인다.
- **코드 위치**: 저장소 `studio/`에 Luau 파일로 두고 Studio에서 `StarterPlayerScripts`(화면)와 `ServerScriptService`(서버)에 설치한다. 장소 파일에 들어가므로 게시하면 같이 올라간다.
- **휴대폰**: 키(M, 킥보드)와 같은 일을 하는 화면 버튼을 같이 만든다.
- **하지 않는 것**: Creator Store 킥보드 모델, 위성 사진을 지도로 쓰기(이용 조건 미확인).
