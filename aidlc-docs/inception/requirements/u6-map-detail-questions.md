# U6 지도 장소 정보 더 상세하게 — Questions

요청(사용자, 2026-10-14): "지도에도 좀 장소 정보 표시가 더 상세하게 있으면 좋겠는데?"
지금 U6 큰 지도(FR-2)는 장소 이름 3개(심원고등학교, 부흥중학교, 옥산공원)만 손으로 넣어 보여 준다. U6는 다른 세션이 만들던 유닛이라(커밋 전 파일이 남아 있다) 이 파일은 U6를 다시 이어갈 세션의 "인지" 단계에서 읽는다.

## 데이터에 이미 있는 것 (세 칸)

- 건물 이름 81개(V-World·OSM): 학교, 행정복지센터, 경로당, 새마을금고, 상가 건물(로얄프라자, 뉴월드 프라자, 골든타워), 빌라·아파트 이름(청솔하이빌, 한신빌라, 광성아파트, 경남센트레빌 등)
- 길 이름 20개(OSM): 길주로, 계남로, 옥산로와 ○○번길들
- 행정동 경계와 이름(OSM, Q8에서 구역 경계로 쓰기로 함)
- **주의**: 건물 이름 중에 개인 이름이 든 것이 있다(예: "단독주택 (사람 이름)"). 개인 이름·번지 주소는 지도에 절대 넣지 않는다.

## Question 1 — 어떤 정보를 보여 줄까 (여러 개 고를 수 있음)
A) **동 이름**(지역 경계와 큰 글씨)
B) **길 이름**(큰길은 항상, 골목 ○○번길은 확대했을 때)
C) **공공·주요 시설**(학교, 공원, 행정복지센터, 경로당, 은행, 교회 등. 종류별 아이콘)
D) **건물 이름**(아파트·빌라·상가 건물 이름. 개인 이름·번지는 거른다)
E) **가게 업종 아이콘**(1층 가게가 있는 건물에 업종 아이콘: 편의점·카페·식당·약국 등. 이름은 맵 간판처럼 지어낸 이름)
F) **버스정류장·지하철역**(OSM에 있으면)

추천: A + B + C + D. E는 간판과 같이 지어낸 정보라 헷갈릴 수 있어 나중에, F는 칸이 늘어 역이 들어오면.

[Answer]: A + B + C + D (사용자, 2026-10-14 인터뷰): 동 이름, 길 이름, 공공·주요 시설, 건물 이름(개인 이름·번지는 거름).
