# Requirements — roblox-map

## 1. 의도 분석 요약

| 항목 | 내용 |
|---|---|
| 사용자 요청 | 실제 동네를 Roblox 롤플레이/타운 맵으로 만든다. 구역을 H3 칸으로 나누고, 칸마다 데이터를 받아 만들고 반복한다. 첫 대상은 부천 심원고등학교 |
| 요청 유형 | New Project (50줄 프로토타입 스크립트 `cells.py` 보유) |
| 범위 | Multiple Components: 데이터 수집, 거리뷰 캡처·분석, Studio 생성, 수작업 다듬기 |
| 복잡도 | Moderate |
| 요구사항 깊이 | Standard |
| 용도 | 개인 취미와 포트폴리오, 1차는 비공개 (Q2=A) |
| 리버스 엔지니어링 | 건너뜀 (Q1=A) |

**기존 자산**: `cells.py`는 위경도 점들로 만든 다각형을 H3 칸으로 채우고(`h3.polygon_to_cells`), 칸마다 Overpass API로 OSM 건물 외곽선과 높이·층수 태그를 받아 `cells/<칸ID>.json`에 저장한다. 건물은 중심점이 속한 칸에만 들어간다. Roblox, 도로, 지형과는 아직 연결되어 있지 않다.

## 2. 대상 구역

- **장소**: 부천시 심원고등학교 (OSM 부지 약 175m × 150m, 위도 37.5037~37.5053, 경도 126.7785~126.7802). 후속 CQ1=B에 따라 부지 전체를 덮는 **H3 해상도 9 칸 3개**를 1차 구역으로 한다.
- **H3 칸 (해상도 9, 변 약 200m)**

| 칸 ID | 중심 | 부지가 걸친 정도 |
|---|---|---|
| `8930e0af13bffff` | 37.50438, 126.77791 | 큼 (학교 중심이 속함) |
| `8930e0af123ffff` | 37.50547, 126.78060 | 중간 |
| `8930e0af12bffff` | 37.50265, 126.78038 | 작음 |

- 이후 확장은 같은 파이프라인을 다른 칸, 다른 동네에 반복해서 적용한다.

### 워크로드 분류 (RESILIENCY-01 초안)

| 구성요소 | 중요도 | 장애 시 영향 |
|---|---|---|
| 데이터 파이프라인 스크립트 (Git) | Low | 재작성하면 됨. Git에서 복구 |
| Roblox 맵 파일 (수작업 포함) | Medium | 수작업 시간이 사라짐. 클라우드 저장과 복사본으로 완화 |
| OSM·거리뷰 원천 데이터 | Low | 다시 받을 수 있음 (거리뷰는 접근 가능할 때) |

## 5. 제외 범위 (1차)

- 건물 내부 입장, 고저차·하천·공원 지형
- 문 열기, 집·가게 소유, 직업, 돈, 차량 등 롤플레이 기능
- 모바일 최적화
- 공개 발행과 수익화 (필요해지면 별도 재검토)

## 6. 가정과 미결 사항

| ID | 내용 |
|---|---|
| A-1 | Roblox Studio는 사용자가 직접 설치했다(2026-10-12 확인). 연결은 별도 서버가 아니라 **Studio 내장 MCP 서버**를 쓴다. 이전에 검토한 `studio-rust-mcp-server`는 아카이브되었다. FR-12의 "Roblox Studio MCP 서버"는 내장 서버를 뜻한다 |
| A-2 | 네이버지도 거리뷰 약관은 확인하지 않고 진행하기로 사용자가 결정했다(2026-10-13). 자동 수집 조항이 있는지는 모른다. NFR-4의 로컬 보관과 NFR-5의 속도 제한, 차단 시 우회 없이 중단은 그대로 적용한다 |
| A-3 | FR-9는 인터뷰에서 "거리뷰 추정 기본, 사용자와 Claude가 같이 확인 후 보정"으로 정했다가, 건축물대장 추가 요청으로 "층수는 건축물대장 1순위, 거리뷰로 검증, 없거나 어긋나면 거리뷰 추정"으로 바뀌었다. **대장을 1순위로 둔 것은 내 추천**이고 네가 "거리뷰가 기본"으로 되돌리길 원하면 순서만 바꾸면 된다. OSM 태그는 기록만 하는 참고값(내 기본값) |
| A-4 | (해결) 기본 스폰 지점은 학교 정문 앞 도로 한 곳으로 확정됐다 |
| A-5 | 스케일 비율(FR-10), 거리뷰 캡처 지점 배치와 360도 캡처 세부(설계 단계), 도로·가로시설의 OSM 부족분 보충 방법(설계 단계), OSM 건물과 건축물대장 항목을 연결하는 방법(주소·지번 또는 위치, 설계 단계)은 미결이다 |
| A-6 | 공개 발행을 결정하면 주거 건물 실사 재현(FR-7)과 거리뷰 기반 파생물을 다시 검토해야 한다 |
| A-7 | (해결) 건물 외곽선과 층수·높이는 V-World 건물통합정보(`LT_C_BLDGINFO`)로 받는다. 시험(2026-10-13)에서 심원고 3칸의 칸 소유 건물이 약 85~203개(OSM은 5~10개)였고 층수는 88~93%, 높이는 45~62%에 값이 있었다. 건축HUB는 U1에서 쓰지 않고 키만 보관한다. 값이 없는 건물은 U3·U4에서 사진으로 판단한다 |
