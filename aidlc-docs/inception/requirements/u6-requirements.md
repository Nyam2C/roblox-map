# U6 미니맵과 킥보드 — Requirements

요청(사용자, 2026-10-14): 오른쪽 위에 지도, 빠르게 이동할 킥보드. 질문 5개 모두 추천안(A)으로 확정(`u6-minimap-scooter-questions.md`, 상시 승인 "지금 다 권고로 ㄱㄱ").

## 기능 요구사항
- **FR-1 미니맵**: 화면 오른쪽 위에 작은 지도. 건물·도로·보행로·공원·운동장을 사각형으로 그린 벡터 지도(Q1=A). 항상 북쪽이 위이고 내 위치 화살표만 카메라 방향으로 돌아간다(Q2=A). 내 위치가 지도 가운데에 온다.
- **FR-2 큰 지도**: M 키 또는 화면 버튼으로 켜고 끈다. 지금 만들어진 칸 전체가 보이고 장소 이름(심원고등학교, 부흥중학교, 옥산공원)과 내 위치가 보인다. 보기만 한다(Q3=A).
- **FR-3 킥보드**: 버튼 하나(K 키, 휴대폰은 화면 버튼)로 어디서나 타고 내린다(Q4=A). 올라탄 모습(걷는 다리 동작 없이 데크 위에 선다)으로 달리고, 속도는 가속·관성·브레이크로 변한다(사용자 추가 요구, 2026-10-14): 밀면 가속해 최고 120(처음 25 km/h, Q5=A였다가 사용자가 80으로, 다시 120으로 올렸다, 2026-10-14), 손을 떼면 서서히 줄고, 가는 방향 반대로 밀면 서고 뒤돌아 출발한다. 두 발을 모아 데크에 서고 두 손으로 손잡이를 잡고(사용자 추가 요구; 팔은 라이더 본인 화면만), 좌우 균형을 잃거나 너무 빠르게 급커브하거나 빠르게 부딪히면 넘어진다(사용자 추가 요구: 실제 킥보드처럼, 기울어지는 쪽으로 밀어 바로잡는다), 걷는 발소리 대신 바퀴 구르는 소리가 속도에 따라 난다(사용자 추가 요구, 소리는 작게). 킥보드 모양이 발 밑에 붙고 다른 플레이어에게도 보인다. 죽거나 다시 태어나거나 나가면 저절로 내린다. 화면에 속도(km/h)가 보인다.
- **FR-4 휴대폰**: 지도와 킥보드 버튼이 화면에 있다. 키 입력이 없어도 모든 기능이 된다.

## 비기능 요구사항
- **NFR-1 프레임**: 지도는 UI 사각형 약 600개(두 칸)이고 한 번만 만든다. 매 프레임 바꾸는 것은 지도 위치 1개와 화살표 1개다. 걷기 평균 ≥ 60 FPS를 유지한다(U2 기준).
- **NFR-2 보안(Security Baseline)**: 킥보드 요청은 클라이언트의 인자를 받지 않는 RemoteEvent 하나다. 서버가 플레이어·캐릭터·체력을 확인하고 0.6초에 한 번만 받는다. 최고 속도와 모양은 서버가 정하고, 가속·브레이크 계산은 자기 캐릭터 물리를 가진 클라이언트가 한다. (클라이언트가 자기 캐릭터를 마음대로 움직이는 것은 Roblox 구조상 막을 수 없다는 한계를 문서에 적는다.)
- **NFR-3 복원력(Resiliency Baseline)**: 서버가 플레이어별 상태(원래 속도, 엉덩이 높이, 킥보드)를 들고 있고 캐릭터 제거·사망·플레이어 나감에서 정리한다. 같은 요청이 두 번 와도 상태가 어긋나지 않는다. 지도 데이터가 없거나 비어 있어도 오류 없이 빈 지도만 보인다.
- **NFR-4 테스트(Property-Based Testing)**: 지도 데이터를 만드는 Python 계산(`src/minimap.py`)은 속성 테스트로 확인한다: 사각형 모서리가 경계 안, 같은 입력이면 같은 결과, 회전 방향 규칙. Luau 스크립트는 Studio Play에서 실제로 실행해 확인한다.
- **NFR-5 범위 밖**: Creator Store 킥보드 모델, 위성 사진 지도, 순간이동, 다른 플레이어 표시, 거치대, 승차 동작(애니메이션)은 하지 않는다. 승차 동작은 나중에 애니메이션 자산으로 더할 수 있다.

## 가정과 한계
- 지도는 `build_luau.py`와 같은 계산(`plan_cell`)에서 나온 항목으로 그린다. 그래서 수작업 학교로 바뀐 건물도 자동 박스 자리가 지도에 나온다. 운동장·공원·부흥중 땅은 `src/minimap.py`의 상수(AREAS)로 둔다.
- 칸이 늘어나면 `minimap.py --cells ...`를 다시 돌려 데이터 모듈만 바꾼다.
- 오른쪽 위에는 Roblox 기본 플레이어 목록이 있어 겹친다. 미니맵을 위해 플레이어 목록 CoreGui를 끈다(클라이언트 스크립트 한 줄, 되돌릴 수 있다).
