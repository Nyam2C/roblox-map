## Question 3 — 좌표 원점과 장소 나누기
원점은 실제 위경도를 Studio 좌표로 바꿀 때의 기준점이다. 지금은 세 칸이 만나는 꼭짓점(37.504169, 126.779628)이 Studio (0, 0, 0)이다. 원점을 나중에 바꾸면 모든 칸과 수작업을 다시 맞춰야 한다.
재 보니 부천 끝(오정·고강·범박·옥길·상동)까지 지금 원점에서 약 1.1만~2.2만 stud다. 이 거리에서 Roblox 좌표 정밀도는 약 0.002 stud라 문제가 없다(정밀도 문제는 보통 수만~수십만 stud 밖에서 생긴다).

B) 구역(장소)마다 원점을 따로. 장소마다 좌표가 0 근처라 편집이 편하지만, 구역 경계에서 좌표 변환이 필요하고 손작업 기준점도 구역별로 바뀐다.
